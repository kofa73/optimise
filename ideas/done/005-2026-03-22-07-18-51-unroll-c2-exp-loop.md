perf: unroll 4-iteration c2 exp loop into explicit guarded calls

Replace the `for(size_t k = 0; k < 4; k++) { if(isotropy_type[k] != DT_ISOTROPY_ISOTROPE) dt_vector_exp(c2[k], c2[k]); }` loop with four explicit individually-guarded `dt_vector_exp` calls. While the compiler may unroll a 4-iteration loop, the runtime array indexing `c2[k]` through a loop variable prevents the compiler from proving that each `c2[k]` access is to a distinct, non-aliasing memory location, potentially forcing all four `dt_aligned_pixel_t` values to be stack-resident rather than register-mapped. By writing `if(isotropy_type[0] != ISOTROPE) dt_vector_exp(c2[0], c2[0])` etc. as four separate statements, each c2 element is accessed with a compile-time constant index, giving the register allocator a better chance to keep c2 values in SIMD registers. Additionally, using the GRAD_ISOTROPIC/LAPL_ISOTROPIC compile-time macro guards (`if(!GRAD_ISOTROPIC) { exp(c2[0]); exp(c2[2]); }`) instead of runtime isotropy_type checks enables dead code elimination to completely remove the exp code paths in the isotropic-unswitched variants.
