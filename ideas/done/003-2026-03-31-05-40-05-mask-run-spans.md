perf: replace per-pixel mask branching with reusable masked row spans

Convert the boolean inpaint mask into per-row contiguous spans or a compact index list once in `process()` and reuse it for every `heat_PDE_diffusion()` call. The hot PDE loop can then avoid the unpredictable `if(opacity)` test on every pixel, run the expensive 3x3 stencil only on masked spans, and keep the pass-through path as simple linear row copies/adds on unmasked runs. That matches the sparse-highlight workload much better than the current branch-per-pixel structure.
