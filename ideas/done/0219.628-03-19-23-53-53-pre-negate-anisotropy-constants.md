perf: pre-negate anisotropy constants to eliminate inner-loop unary negations

The exponents for the diffusion tensor are computed per-pixel using `c2[k] = -magnitude * anisotropy[k]`. Since `anisotropy` is constant for the entire pass, we can pre-negate these array values once outside the main loop (`neg_anisotropy[k] = -anisotropy[k]`). This replaces the inner-loop computation with a direct multiplication (`magnitude * neg_anisotropy[k]`), stripping an unnecessary floating-point sign flip from the core gradient pass.

outcome: not applicable

The code structure has changed, making this specific optimization infeasible. The inner loop no longer computes exponents using `c2[k] = -magnitude * anisotropy[k]`. Instead, it now uses a pre-computed `half_anisotropy` array (e.g., `c2[0][c] = -magnitude_grad * half_anisotropy[0]`) which has already modified the constant. Furthermore, according to the provided "Learnings from past experiments," pre-negating anisotropy constants is explicitly listed as an anti-pattern that unexpectedly regressed performance and should be avoided.
