perf: trim masked PDE work to per-scale contiguous influence intervals

After `build_mask`, derive for each wavelet scale a per-row `[x0, x1]` interval expanded by that scale’s atrous reach (`mult * H`). In `heat_PDE_diffusion`, run the expensive neighbour/gradient/kernel path only inside that interval and use the cheap `HF + LF` reconstruction outside it. This keeps the existing traversal pattern and removes substantial whole-image work on sparse highlight masks without introducing general span machinery.
