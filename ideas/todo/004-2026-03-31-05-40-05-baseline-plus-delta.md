perf: split masked reconstruction into a fast base add and a sparse PDE delta pass

For the masked CPU path, first reconstruct the full frame with a tight pass like `out = LF + HF * strength`, then run a second pass over only masked pixels to add the diffusion correction and clamp. This separates the cheap, highly vectorizable baseline reconstruction from the heavy masked stencil work, reducing register pressure and control-flow mixing inside `heat_PDE_diffusion()`. It is especially attractive for the target instance because `strength` is exactly `1`.
