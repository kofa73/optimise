perf: crop diffuse wavelet processing to mask-driven scale halos

Build a CPU-only sparse path for `src/iop/diffuse.c` that computes a bounding box or tile list from the inpaint `mask`, dilates it by the current wavelet support (`1 << s`) per scale, and runs decomposition/reconstruction/PDE only inside those regions while copying the untouched exterior straight through. For the `inpaint highlights` preset, the masked area is usually small, so this attacks the largest remaining cost: repeatedly processing the whole frame for 33 iterations even though only a small masked region can change.
